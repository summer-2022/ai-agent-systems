# Pragmo Lite

## Purpose
Pragmo Lite is an educational agent that helps English learners practice real-life speaking situations.  
It focuses on pragmatic appropriateness, politeness, and natural expression.

### Core Features
1. Generates a speaking practice scenario.
2. Analyzes the learner's English response.
3. Provides feedback and a better expression.

## Graph Structure
START → scenario_node → feedback_node → END
